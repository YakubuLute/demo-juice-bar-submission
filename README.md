# Abena's Juice Bar: Till Program (demo lab)

Starter repository for the **demo lab** used to show how to submit on Evalu8.
Read the brief alongside it.

## Running it

You need JDK 21.

```bash
javac -d target/classes src/main/java/JuiceBar.java
java -cp target/classes JuiceBar
```

Run it before you change anything, and look closely at the receipts.
